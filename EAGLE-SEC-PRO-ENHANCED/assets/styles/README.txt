EAGLE-SEC PRO — Theme Styles
============================

dark_theme.qss    Primary dark cybersecurity theme (default)

To create a custom theme:
1. Copy dark_theme.qss to my_theme.qss
2. Edit the CSS variables at the top (:root section)
3. In Settings > Interface, your theme will be available

Color variables:
  --bg         Main background
  --surface    Card/panel background
  --border     Border color
  --accent     Primary accent (default: neon blue #00D4FF)
  --accent2    Secondary accent (default: neon green #00FF88)
  --text       Primary text
  --muted      Muted/secondary text
  --danger     Error/danger color
  --warn       Warning color
